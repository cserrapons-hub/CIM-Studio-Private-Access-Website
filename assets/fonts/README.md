Montserrat Light 300 and Regular 400, self-hosted Latin WOFF2 subsets.
Source: https://github.com/googlefonts/Montserrat/tree/93c725e051a647a975c2cf225e8330bdf2b198e1/fonts/ttf
License: OFL-Montserrat.txt (SIL OFL 1.1).
Subsets preserve layout features and include U+0000–024F, U+2000–206F, U+20AC and U+2197.
Generated with fontTools and Brotli outside the deployment build. The original family/design is retained.
The build copies committed WOFF2 files; no font service or new application dependency.
Filenames contain the SHA-256 prefix of the exact bytes. Initial Light/Regular font preloads total approximately 58 KB; Medium is loaded on demand.
Georgia remains the system font used by the existing headings; it is not redistributed.

Montserrat Medium 500 is also self-hosted for entered form values, from the same upstream source and OFL license. Its fingerprint is validated in tests. Unlike the existing 300/400 faces, it is not preloaded and is requested when needed.
